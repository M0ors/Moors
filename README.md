# Next.js + Supabase Starter

A modern full-stack web application built with **Next.js**, **TypeScript**, **Supabase**, and **Tailwind CSS**.

## 🚀 Features

- ⚡ Next.js App Router
- 🎨 Tailwind CSS
- 🔐 Supabase Authentication
- 🗄️ Supabase Database
- 📦 TypeScript
- 📱 Responsive Design
- 🌙 Modern Project Structure

## 🛠️ Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
- ESLint
